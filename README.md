# 重庆大学 GSing 机器人战队

欢迎来到重庆大学 GSing 机器人战队官方网站项目。这里记录战队动态、机器人项目与赛事成果，也为关注战队的朋友提供交流空间。

[访问战队官网](https://www.cqu-gsing.tech)

## 在这里了解我们

- **战队介绍**：认识 GSing，了解战队与各组的方向。
- **项目展示**：查看机器人项目介绍、照片和视频。
- **战队动态**：关注赛事进展、团队故事与招新信息。
- **荣誉记录**：浏览比赛成绩与获奖证书。
- **交流互动**：注册登录后，可以参与文章评论和留言板交流。

## 2026 赛事荣誉

在第二十五届全国大学生机器人大赛 ROBOCON 仿生足式机器人挑战赛中，重庆大学两支队伍获得以下奖项：

| 队伍 | 障碍赛 | 任务赛 |
| --- | --- | --- |
| 一队 | 一等奖 | 三等奖 |
| 二队 | 二等奖 | 三等奖 |

[查看获奖详情与证书](https://www.cqu-gsing.tech/articles/2026-awards)

获奖页面支持浏览四张证书，点击可查看原始 PDF；手机端可左右滑动查看。
